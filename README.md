# 🌱 EcoEnergy — Interactive Energy Dashboard

## 📖 Pengenalan Aplikasi

**EcoEnergy** adalah aplikasi mobile interaktif berbasis Flutter yang dirancang untuk memperkenalkan berbagai sumber energi terbarukan, seperti energi surya, energi angin, dan energi air. Aplikasi ini mengusung tema **Sustainable Development Goals (SDGs) poin 7, yaitu Affordable and Clean Energy**, yang berfokus pada akses energi yang terjangkau, andal, berkelanjutan, dan modern.

EcoEnergy menggabungkan tampilan antarmuka yang sederhana dan informatif dengan fitur interaksi berbasis gesture. Pengguna dapat menjelajahi informasi energi terbarukan melalui kartu interaktif yang merespons gerakan sentuhan secara langsung. Dengan demikian, aplikasi ini tidak hanya menyajikan informasi, tetapi juga memberikan pengalaman penggunaan yang lebih menarik dan dinamis.

## ✨ Fitur Utama

- **Double Tap:** Memperbesar atau mengembalikan ukuran ikon energi dengan mengetuknya dua kali.
- **Scale/Pinch Gesture:** Mengubah ukuran ikon energi menggunakan gerakan dua jari.
- **Swipe/Horizontal Drag:** Berpindah antar kartu informasi energi dengan menggeser kartu ke kiri atau kanan.
- **Interactive Visual Feedback:** Menampilkan perubahan visual dan teks status sebagai respons terhadap interaksi pengguna.
- **Informasi Energi Terbarukan:** Menyediakan informasi singkat mengenai energi surya, angin, dan air.

## 🎯 Tujuan Aplikasi

1. Memperkenalkan jenis-jenis energi terbarukan kepada pengguna.
2. Menerapkan interaksi gesture pada aplikasi mobile menggunakan Flutter.
3. Memanfaatkan `GestureDetector` untuk mendeteksi berbagai gerakan sentuhan.
4. Menerapkan manajemen state lokal menggunakan `StatefulWidget` dan `setState()`.
5. Mendukung peningkatan kesadaran mengenai pentingnya energi bersih dan berkelanjutan.

## 🛠️ Teknologi yang Digunakan

- **Flutter:** Framework untuk membangun aplikasi mobile.
- **Dart:** Bahasa pemrograman yang digunakan dalam pengembangan aplikasi.
- **GestureDetector:** Widget untuk menangani interaksi gesture pengguna.
- **StatefulWidget & setState():** Digunakan untuk mengelola state dan memperbarui tampilan aplikasi secara dinamis.
- **Material Design:** Panduan desain antarmuka untuk menghasilkan tampilan yang konsisten dan mudah digunakan.

## 🚀 Cara Menjalankan Aplikasi

1. Pastikan Flutter SDK dan Dart sudah terpasang.
2. Clone atau unduh repository project ini.
3. Buka terminal pada direktori project.
4. Jalankan perintah berikut untuk mengunduh dependensi:

   ```bash
   flutter pub get
   ```

5. Jalankan aplikasi menggunakan emulator atau perangkat Android:

   ```bash
   flutter run
   ```
